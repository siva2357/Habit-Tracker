# Project Structure & Themes

## Pages
- **Splash Screen**: Initial loading screen.
- **Login / Registration**: User authentication.
- **Home Screen**: Card-based navigation to select a module.
- **Dashboard**: Complete overview of activities, progress, and reminders.
- **Habit Tracker**: Track daily habits, streaks, and consistency.
- **Day Planner**: Structured timetable for daily schedules.
- **Goal Planner**: Set, organize, and monitor goals.
- **My Projects**: Manage projects, tasks, and deadlines.
- **My Fitness**: Track health, workouts, and nutrition.
- **My Finances**: Manage budgets, expenses, and savings.

## Themes

**Design Style**:
- Modern desktop application feel.
- Minimalistic, clean, and spacious layout.
- Inspired by Windows 11 and macOS aesthetics.
- Features smooth animations, rounded cards, soft shadows, and subtle glassmorphism.
- Fully responsive design.

**Color Modes**:
- Support for both Light and Dark themes.

**Navigation**:
- Home Screen functions as a central hub with large interactive module cards.
- Consistent inner layout with a top header and an optional left navigation sidebar for module-specific features.
